# 🤖 AI TikTok Middleware

وسيط ذكي لإنشاء ومشاركة محتوى TikTok باستخدام الذكاء الاصطناعي

**Intelligent middleware for creating and sharing TikTok content using AI**

---

## ✨ المميزات الرئيسية

- 🎬 **توليد أفكار الفيديوهات** - استخدام OpenAI لإنشاء أفكار فريدة وفيروسية
- 📝 **كتابة السيناريوهات** - إنشاء نصوص احترافية للفيديوهات
- 🎤 **تحويل النص إلى صوت** - استخدام ElevenLabs لأصوات احترافية
- 🎥 **إنشاء الفيديوهات** - دمج الصور والصوت والنصوص تلقائياً
- 📤 **النشر التلقائي** - رفع الفيديوهات على TikTok بدون تدخل يدوي
- 📅 **الجدولة الذكية** - جدولة النشر في أوقات محددة
- 📊 **التحليلات** - تتبع أداء الفيديوهات

---

## 🛠️ المتطلبات

### البرامج المطلوبة:
- Python 3.8+
- Chrome/Chromium Browser
- FFmpeg (لمعالجة الفيديوهات)

### الحسابات المطلوبة:
- OpenAI API Key
- ElevenLabs API Key
- حساب TikTok

## 📦 التثبيت

### 1. استنساخ المستودع
```bash
git clone https://github.com/rami9754788/AI-TikTok-Middleware.git
cd AI-TikTok-Middleware
```

### 2. إنشاء بيئة افتراضية (اختياري لكن موصى به)
```bash
python -m venv venv
source venv/bin/activate  # على Linux/Mac
venv\Scripts\activate     # على Windows
```

### 3. تثبيت المكتبات
```bash
pip install -r requirements.txt
```

### 4. إعداد المتغيرات البيئية
```bash
cp .env.example .env
```

ثم عدّل ملف `.env` وأضف مفاتيح API الخاصة بك:
```env
OPENAI_API_KEY=your_openai_api_key
ELEVENLABS_API_KEY=your_elevenlabs_api_key
ELEVENLABS_VOICE_ID=your_voice_id
TIKTOK_USERNAME=your_tiktok_username
TIKTOK_PASSWORD=your_tiktok_password
```

## 🔐 الأمان

⚠️ **تنبيهات أمان مهمة:**

1. **لا تشارك ملف `.env`** - يحتوي على مفاتيح سرية
2. أضفه إلى `.gitignore`:
```bash
echo ".env" >> .gitignore
```

3. استخدم متغيرات بيئية قوية للإنتاج
4. غيّر كلمة مرور TikTok بانتظام

## 🐛 استكشاف الأخطاء

### المشكلة: فشل توصيل OpenAI
```
❌ خطأ: API key not found
```
**الحل:** تأكد من إدخال مفتاح API الصحيح في `.env`

### المشكلة: فشل تسجيل الدخول إلى TikTok
```
❌ خطأ في تسجيل الدخول
```
**الحل:** 
- تحقق من اسم المستخدم وكلمة المرور
- قد تحتاج إلى تفعيل التحقق ثنائي
- استخدم كلمة مرور خاصة (بدون 2FA)

### المشكلة: فشل في إنشاء الفيديو
```
❌ خطأ في إنشاء الفيديو
```
**الحل:**
- تأكد من تثبيت FFmpeg
- تحقق من وجود الملفات الصوتية والصور
- تحقق من مساحة التخزين
